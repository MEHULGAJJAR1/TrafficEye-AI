# Included original synthetic sample

`traffic_demo_60s.mp4` is a 60.000-second, 12 FPS, 960 × 540 H.264/YUV420P video generated by this project's drawing code. It is original synthetic artwork, **not footage from a traffic camera**. No identifiable people, real licence plates or third-party clips are included. The scene and its generated manifest are dedicated to the public domain under **CC0-1.0** (see `LICENSE-CC0.txt`).

The checksum and scripted actors are in `demo_manifest.json`. Demo inference is enabled only when uploaded file bytes match this sample's verified SHA-256. The worker derives scripted boxes and confidence values from these actors; it does NOT run an AI model. Snapshot overlays, dashboard badges and report rows explicitly carry demo provenance.

The upload interface accepts this video through **Import synthetic sample** or normal file upload. Choose Scripted demo, then Start processing. Both the default 60-second span and Full video work. This is an end-to-end software fixture, not a machine-learning evaluation dataset.

## Regenerate offline

Stop the backend before regenerating (its sample checksum is cached at startup). After installing requirements, from the project root:

```powershell
.\.venv\Scripts\python.exe scripts\prepare_sample.py --force
```

`imageio-ffmpeg` supplies an encoder binary through its installed wheel. No invented remote download URL or separate FFmpeg installation is required. If your platform's wheel has no binary, install FFmpeg from its official distribution and set `IMAGEIO_FFMPEG_EXE` to its executable.

## Use real footage

Place a legally obtained MP4, AVI or MOV in this folder or anywhere on your computer, then upload it. You are responsible for permission, privacy, signage and retention requirements. Real footage cannot use the synthetic sample's scripted detections; configure a suitable custom model for actual AI processing. Browser previews may be transcoded to H.264; inference always uses the original uploaded file.
